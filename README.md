# Single-Channel-Relay-Module

Designed a single-channel relay module PCB in KiCad, developing the schematic and assembled board layout. 

Integrated a SANYOU SRD SPDT electromagnetic relay, MMBT2222A NPN transistor switching circuit, and MRA4003T3G flyback diode for relay control and inductive-load protection.
